# Shared task specification

This directory will contain the task definition that both independent tracks receive before substantive work begins.

The specification is **not frozen yet**. Do not infer missing scientific details from the repository name alone.

When the exam task is supplied, freeze here the information actually needed for a fair comparison: physical system and structure, target quantities, required method/approximations, allowed or required software, required inputs/data, numerical tolerances or convergence expectations, deliverables, and acceptance criteria. Record any deliberately unspecified choices as unspecified rather than resolving them differently for the two tracks.

Once frozen, changes that affect the scientific task should be explicit and versioned. Both tracks should start from the same specification revision.
