# AI-autonomous track

This directory is the independent AI-autonomous track.

Once `shared/spec/` is frozen, the AI track may choose its numerical workflow, construct code and runnable inputs, test and debug them, run calculations when compute access permits, assess convergence and validation, inspect failures, iterate, and audit its own result.

It must not inspect or use intermediate reasoning, numerical results, or conclusions from `human-control/` before the comparison gate. If a required compute resource, executable, dataset, pseudopotential, or external service is unavailable, that limitation should be recorded explicitly rather than silently bypassed.

Suggested subdirectories:

- `inputs/` — calculation inputs generated by the AI track;
- `scripts/` — automation, analysis, and validation scripts;
- `runs/` — lightweight run records and manifests; keep bulky scratch data out of Git;
- `results/` — compact processed results, tables, figures, and AI conclusions.

The track begins from the same frozen specification as `human-control/` and remains independent until the comparison gate.
